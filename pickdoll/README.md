# PickDoll web

브라우저에서 실행되는 7개 랜덤 인형 뽑기 게임. PC 키보드와 휴대폰 터치 조작을 지원한다.

- 물리 모델은 shchun/PickDoll의 claw.xml에서 가져왔다.
- physics.js는 Python 상태 전환과 집게 제어를 JavaScript로 옮긴 코드다.
- 공식 @mujoco/mujoco 4.0.1 단일 스레드 WASM과 Three.js 0.187.0을 고정 버전 CDN에서 불러온다.
- 음악·효과음은 원본 프로젝트에서 합성한 WAV 파일이며 시작 버튼을 누른 후 재생한다.
- 정적 HTTP 서버로 저장소 루트를 제공한 뒤 /pickdoll/을 연다. 설치나 빌드 단계는 없다.
- 인터넷 연결과 WebGL 2를 지원하는 브라우저가 필요하다.

방향키 이동, Shift 저속 이동, Ctrl+방향키 1mm 이동, Z/X 회전, Enter 뽑기, Tab/1~5 카메라, R 새 판, M 소리 켜기/끄기. 터치 화면에서는 방향키와 회전·뽑기 버튼을 사용한다.


## 플레이 피드백 반영

- 일반 조준은 초당 7.5cm에서 12cm로 높였다. Shift 8mm/s와 Ctrl 1mm 이동은 유지한다.
- 상승은 초당 18cm, 출구 복귀는 축별 최대 초당 18cm로 높였다. 복귀에는 가속 구간이 있다.
- 토끼, 곰, 고양이, 판다, 여우, 강아지, 펭귄을 머리·몸통·팔다리로 구성했다.
- 천 질감과 약 7%의 눌림·복원 연출을 더했다. 물리는 강체와 유연한 접촉 설정을 사용하며 전체 연체 변형은 시뮬레이션하지 않는다.
- 매 시도 약 12%는 약한 그립, 나머지는 보통 그립 범위에서 유지 토크를 뽑는다. 닫을 때는 충분한 힘을 주고 상승하면서 해당 힘으로 전환한다. 실제 접촉과 마찰에 의해 인형이 미끄러질 수 있다.
- 동일한 배치·조준의 강/약 비교 시험에서 보통 힘 7종 모두 배출, 약한 힘 7종 모두 실패를 확인했다. 이는 지정된 시험 조건의 결과이며 플레이 승률을 뜻하지 않는다.


### 집기 난이도 재조정

약한 집게의 비율을 28%에서 12%로 줄이고, 약한 힘의 범위도 올렸다. 정상 유지 토크는 0.065~0.080 N·m, 약한 토크는 0.020~0.035 N·m이다. 중심 보정은 3cm까지 지원한다. 집게가 닫힌 뒤 0.60초 기다리고 상승하며, 유지 힘으로 0.55초에 걸쳐 전환한다.

같은 난수 배치와 조준 오차를 사용한 14회 비교 시험에서 기존 설정은 9회, 새 설정은 13회 획득했다. 이 표본에서 약한 힘이 나온 횟수도 서로 달랐으며, 실제 플레이 승률을 보장하는 수치는 아니다.


### 내부 조명과 관성

모델 색을 sRGB로 해석해 밝게 뜨는 현상을 줄였다. 외부 조명을 낮추고 내부에 세 개의 작은 조명을 배치해 인형과 상판이 밝게 보이도록 했다. 분리된 LED 조각은 불투명한 유백색 커버가 있는 여섯 개의 연속 띠로 교체했다.

집게는 수직축 회전 외에 두 개의 수동 진자 관절을 사용한다. 가감속 때 살짝 기울고 감쇠하며 멈춘다. 관절 한계는 약 ±3도이며, 집기·상승 중에는 스프링과 감쇠를 높여 안정시킨다. 정밀 조작과 중심 보정, 약한 집게 비율 12% 설정을 유지한다.

### 자유 시점과 조준 표시

게임 화면을 마우스나 손가락으로 드래그하면 관점을 연속적으로 바꿀 수 있다. 이동 방향은 카메라와 관계없이 기계 정면 기준으로 고정한다. ↑는 뒤쪽, ↓는 앞쪽, ←/→는 기계의 왼쪽/오른쪽이다. 키보드·터치·미세 이동 모두 같은 기준을 사용한다. 기존 다섯 시점과 Tab 전환도 지원한다. 조준 링은 선을 굵게 하고 짙은 테두리와 밝은 연두색을 조합해 바닥과의 대비를 높였다.
